# RoyalShuffle 0.5.0-rc.1

This prerelease is the first RoyalShuffle Linux CLI release candidate. Native
Linux acceptance is still pending. It has been validated under Ubuntu WSL2 and
automated Ubuntu CI and is intended for native-Linux acceptance testing.

Highlights:

- Linux-native command-line interface with headless operation and no Tkinter
  requirement
- XDG-native config, state, data, diagnostics, and export locations
- Spotify OAuth authentication, saved-session reuse, and token refresh
- Playlist discovery and managed-output filtering
- True Random playlist shuffle
- CSV export and exact-order CSV import with duplicate preservation
- Explicit partial-write safety and reporting
- Installable Python wheel and source distribution
- Validation on Python 3.10 and 3.12

Install the attached wheel, or follow the source-install instructions in the
README. This release does not include PyPI publication, a standalone Linux
binary, a distro package, a native Linux GUI, Android changes, or a new Windows
installer.
