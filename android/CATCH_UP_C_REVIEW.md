  playlist selection. Resume uses saved source/operation identity, checked under the mutation lease.

  its draft; Artist Separation stays independent; each new Deal has editable `<Source> - Deal N` naming;
  status restores locally; auth cancellation preserves durable state; pending actions cannot silently
  abandon intent. Start New Rotation retains current-source loading and confirmation semantics.

  `Randomized by RoyalShuffle | Spotify Companion`; ordinary discovery additionally recognizes
  `True-randomized copy generated by RoyalShuffle`. New Opportunity Deals use exactly
  `Dealt by RoyalShuffle | Spotify Companion`. Deal metadata is descriptive only. Existing remote
  metadata is not rewritten. No Opportunity adoption by names/descriptions occurs.
- PASS completed Deals: completed output IDs are not stored in a permanent Opportunity binding or
  completed-Deal registry. Completed playlists are preserved and become source-eligible.
- PASS shared integration: ordinary and Opportunity workflows and registry mutations share the process
  coordinator. Existing ordinary Full/60M/Custom planning, duplicate-occurrence behavior, naming,
  managed reuse, stale-output resolution, and Artist Separation semantics remain intact.
- PASS Start New Rotation: builds a fresh current-source snapshot, keeps the candidate separate until
  delivery succeeds, restarts numbering at Deal 1, and preserves old intent if naming is canceled.
